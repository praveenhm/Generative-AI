### Text Features

| Feature | Description |
|---------|-------------|
| Semantic Chunking | Breaks up the text into meaningful chunks. |
| Text Chunks | Chunks of text extracted from the main content. |
| Vector Representations | Vector representations of the text chunks. |

---

### Image Features

| Feature | Description |
|---------|-------------|
| Raw Image | The original image. |
| Standardized Image | Image standardized to a fixed size. |
| Segmentation Masks | Masks that segment the image. |
| Bounding Boxes | Boxes that highlight objects in the image. |
| Object Labels | Labels identifying objects inside bounding boxes. |
| Image Vectors | Vector representations of the image. |
| Feature Points | Specific points of interest or features within the image. |

---

### Audio Features

| Feature | Description |
|---------|-------------|
| MEL Spectrogram | Represents the short-term power spectrum of a sound. |
| Text Transcription | Text version of the audio content. |
| Speaker Accent | Detection of the accent of the speaker. |
| Gender Detection | Detects the gender of the speaker. |
| Language Detection | Detects the language being spoken. |

---

### Video Features

| Feature | Description |
|---------|-------------|
| Keyframes | Main frames extracted from the video. |
| Temporal Encoding | Features like action descriptions over time. |
